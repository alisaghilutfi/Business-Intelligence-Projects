# Nashville Housing Data Cleaning & Transformation (SQL Server)

## 📌 Project Overview

This project demonstrates practical SQL skills using **Microsoft SQL Server (SSMS 21)** through a full data cleaning and transformation workflow on the *Nashville Housing* dataset. The goal is to prepare raw housing data for downstream analytics while showcasing real-world SQL techniques recruiters expect from data analysts.

The project focuses on:

* Data quality assessment
* Data cleaning and standardization
* Handling NULL values
* String parsing and column normalization
* Deduplication using window functions
* Schema modification using `ALTER TABLE`

All transformations are performed directly in SQL, simulating a realistic production-style workflow.

---

## 🛠️ Tools & Technologies

* **Database**: Microsoft SQL Server
* **IDE**: SQL Server Management Studio (SSMS 21)
* **Language**: T-SQL

---

## 📂 Dataset

* **Table Name**: `PortfolioProject.dbo.NashvilleHousing`
* **Domain**: Real estate / housing transactions

The dataset contains information about property sales in Nashville, including addresses, sale dates, ownership details, and transaction metadata.



## ✅ Key Skills Demonstrated

* Data cleaning & transformation in SQL
* Self-joins for data enrichment
* Window functions (`ROW_NUMBER()`)
* Schema evolution with `ALTER TABLE`
* String manipulation & date conversion
* Writing readable, modular SQL scripts

## 🚀 How to Use This Project

1. Import the Nashville Housing dataset into SQL Server
